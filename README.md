# Trainee Polls

Stateful scheduling polls administered by Ethan MacDonald/Hermes.

- Public poll pages live in unguessable event-specific directories.
- The canonical generators and administrative records are maintained in the trainee organization Dropbox workspace.
- New polls should be deployed from a `hermes/*` branch and verified through the live GitHub Pages URL before their invitation draft is finalized.
- Default meeting format is Zoom unless Ethan specifies otherwise.
- Poll pages must clear the participant-name field on reload/reopen and must not persist names in browser storage.
